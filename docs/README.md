# NexusDB Docs

Planning and reference documentation for NexusDB, kept separate from the code so
it doesn't clutter the repo root.

| Doc | What it's for |
|---|---|
| [ARCHITECTURE.md](./ARCHITECTURE.md) | How the system is built today — components, data flow, known limitations |
| [ROADMAP.md](./ROADMAP.md) | Phased plan to take this from a working prototype to a portfolio-grade, production-ready project |
| [PRODUCTION_READINESS.md](./PRODUCTION_READINESS.md) | Checklist of everything expected of a "production" service, mapped to current status |
| [API_REFERENCE.md](./API_REFERENCE.md) | REST API surface as it exists today |

Start with `ARCHITECTURE.md` if you're new to the code, then `ROADMAP.md` for what
to build next.
