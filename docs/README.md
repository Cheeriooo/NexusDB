# NexusDB Docs

Planning and reference documentation for NexusDB, kept separate from the code so
it doesn't clutter the repo root.

| Doc | What it's for |
|---|---|
| [SETUP.md](./SETUP.md) | Clone-to-running setup guide (Docker or local dev), first API calls, troubleshooting |
| [ARCHITECTURE.md](./ARCHITECTURE.md) | How the system is built today — components, data flow, known limitations |
| [API_REFERENCE.md](./API_REFERENCE.md) | REST API surface as it exists today |
| [BENCHMARKS.md](./BENCHMARKS.md) | HNSW vs. brute-force recall/latency numbers |

New to this repo and want to run it? Start with `SETUP.md`. New to the code
and want to understand it? Start with `ARCHITECTURE.md`.
