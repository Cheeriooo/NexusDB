# NexusDB UI

React 19 + Vite console for NexusDB: collections, vector CRUD, search, and a
Three.js "Deep Field" 3D visualizer.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to http://localhost:8000
npm run build    # production build to dist/
npm run lint
```

See the [root README](../README.md) and [`docs/SETUP.md`](../docs/SETUP.md)
for running this alongside the API.
